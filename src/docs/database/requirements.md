# Job Tracker - Database Requirements

## 1. Users
- Users can register and log in.
- Users can manage their profiles.

## 2. Companies
- Users can save companies.
- Companies can have multiple job listings.

## 3. Jobs
- Jobs belong to companies.
- Jobs have titles, descriptions, locations and salary ranges.
- Jobs can require multiple skills.

## 4. Applications
- Users can apply for saved jobs.
- Each application has a status.
- Users cannot apply to the same job twice.

## 5. Interviews
- An application can have multiple interviews.
- Each interview has a date, type and outcome.

## 6. Notes
- Users can add notes to applications.
